# 打纸杯小玩法 · 产品设计 v1（冻结稿）

> 状态：2026-10-15 冻结。迭代不得突破合规红线（见 compliance.md）。

## 一句话定义

直播间内的**协作式解压小游戏**：观众用弹幕免费击发、用礼物加量，全房间一起把一排卡通纸杯打倒，只计命中 / 连击 / 高光时刻——无阵营、无输赢、无回兑。

## 核心循环（单局 30-60s）

```
待机 → 开始一局 → 弹幕免费击发 / 礼物加量（多发/双发/彩虹清杯）
     → 命中：杯子累积随机倾角 + 连击 + 大字反馈 + 卡通音效
     → 全部杯子倒下（清杯）或 3 分钟到 或 主播手动结束
     → 结算（总命中/最高连击/得分/高光时刻数）→ 待机
```

## 触发与映射（触发层）

| 事件 | 效果 | 说明 |
|---|---|---|
| 弹幕（任意） | 免费击发 ×1 | 带节奏，人人可参与；防刷：同一用户高频弹幕平台侧限流 |
| 礼物 · rose | 多发一发 | 礼物 = 加量器，不是入场券 |
| 礼物 · heart | 双发（一次命中叠 2 次倾角） | 5 发即可凑满 10 次计数门 |
| 礼物 · rocket | 彩虹清杯 | 打整圈底杯 + 高光时刻 |

> M2 起以平台"礼物置顶（≤6 个配置礼物）"为准，礼物 id 映射表在主题层可换。

## 规则与物理（规则层 + 物理层）

塔是**空心圆环杯墙**（12 层 × 27 只，转盘持续旋转），底部正前方有固定击发点。
小豆从击发点**直线上升**、不锁定任何杯子：撞到屏幕位置最靠前的那只杯；正前方那一列空了就继续往上打后排，前后都没有就是空击。

- **随机倾角叠加**：每次命中从 3 个候选值（0.030 / 0.038 / 0.046 rad）随机取一个，叠加到该杯、不回正
- **倒的判定（或关系）**：累计命中次数 ≥ 10，或累计倾角 ≥ 0.42 rad；9 次即使全是最大值也只到 0.414，所以"至少 10 次"是硬约束
- **转盘转速是玩法约束**：一只杯在正前方要停留 ≈1.16s（27 杯 × 0.1 rad/s），才够 80ms 连发打满 10 次；转速调大会让命中摊到多只杯上
- **支撑判据**：一只杯站立，当且仅当它的**两只支撑杯都还活着**（嵌在下层杯缝里）；只剩一只 = 悬挑 = 坠
- **倒向缺口**：每只杯倒下时朝同层最近的那个缺口倒，缺口像 V 形向两边张开，不是随机左右
- **塌落传播**：结构失效的杯子排队 110–280ms 再倒 → 一层层传上去（多米诺）；纸杯无粘接，缺口逐层变宽，但整圈不会被一次清空
- **计分**：总命中、最高连击、高光时刻（连击 ≥5）；得分 = 击倒杯数 × 10 × 连击倍率
- **结束条件**：清杯（全部倒下）或 3 分钟上限，二者先到先结算
- **无输赢、无阵营**：全房间共同打同一座塔

## 视觉基调（主题层）

- 卡通手绘风；杯子带原创表情（两只眼睛 + 微笑），无第三方 IP
- **禁**：仿真枪、枪械造型、血腥、写实枪声
- 音效：pong（命中）/ boing（连击）/ duang（高光），全部 WebAudio 合成
- 色板：天空蓝 + 橙杯 + 红点缀（占位，M3 前换 AI 生成卡通资产）

## 技术架构（四层）

```
触发层 trigger.ts        事件 → ShotSpec（本地模拟 / M2 平台推送）
规则层 rule.ts           纯逻辑：命中/连击/得分（可单测、确定性种子）
物理效果层 physics.ts     倾倒进度/旋转/下落（渲染无关）
主题层 theme.ts           色板/话术/礼物映射（换皮 = 换 ThemePack）
```

宿主：Web（PixiJS），M3 前用 Tauri 2 打 Windows 安装包（主播房间运行）。

## 主播侧要求（平台规则）

- 真人实时开麦互动（官方弹幕游戏渠道要求）
- 话术走合规包：命中 / 没倒 / 倒了 / 连击 / 高光时刻；禁赢输押赔
