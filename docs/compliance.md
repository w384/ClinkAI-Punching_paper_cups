# 合规自检清单（审核材料 + 代码硬规则）

> 依据：涉赌三要素（最高检口径）、抖音《直播行为规范》、网信办打赏新规负面清单。
> 本清单是 M3 审核材料的一部分，也是每次发版前的自查表。

## 一、红线（代码中不得出现任何对应能力）

| # | 红线 | 本项目的实现方式 |
|---|---|---|
| 1 | 资金单向：礼物只进不出 | 代码中**不存在**回兑/兑换/下分/返水/提现/站外交易字段与接口 |
| 2 | 无对抗、无阵营、无输赢 | 全房间协作打杯；无阵营 API；结算只有命中/连击/高光 |
| 3 | 礼物不是入场券 | 弹幕免费可玩；礼物仅"加量"（多发/特效） |
| 4 | 无门槛式/诱导式打赏 | 无 PK、无虚假榜单、无"刷 X 元解锁" |
| 5 | 卡通视觉 | 无仿真枪、无血腥、无写实武器音效 |
| 6 | 真人实时 | 主播真人开麦；数字人仅在 M5 且满足五条件 |
| 7 | 原创形象 | 杯子表情为原创，无第三方 IP |

## 二、禁用词库（主播话术 + 游戏内文案 + 审核材料）

禁用：赌、押、赔率、包中、返水、下分、上分、返点、洗、走水、赢、输、庄家、盘口

替换对照：

| 禁用 | 替换 |
|---|---|
| 赢 / 输 | 命中 / 没倒 |
| 押一发 | 来一发（击发） |
| 赌赢全场 | 全部打倒（清杯） |

> 游戏内文案已全部走 `theme.words` 合规话术包（命中/连击/高光时刻）。

## 三、发版前自查（每次提交审核）

- [ ] 文案扫描：禁用词库 0 命中
- [ ] 音效审查：无写实武器音
- [ ] 视觉审查：无仿真枪/血腥/第三方 IP
- [ ] 资金流审查：无出向字段
- [ ] 礼物映射：全部为加量类，无解锁类
- [ ] 演示视频：主播真人出镜开麦
- [ ] 软著证明在有效期内
